# Audit report — 2026-10-29

Scope: the full `notion-2api-web` tree (application, dashboard, scripts, tests,
configuration templates and documentation).

## Fixed in this pass

- Removed unused imports, obsolete exception classes, route helpers and legacy
  client-side tool-call heuristics (~650 lines).
- Hardened Prometheus label rendering against quote/backslash/newline injection.
- Corrected the GitHub Actions Python matrix expression and refreshed the
  Dockerfile base image.
- Replaced real temporary-mail domains, admin credentials and Clash group names
  in configuration defaults/templates with placeholders.
- Replaced aggressive/CTF-style prompt-injection text with a neutral,
  provider-agnostic system prompt.
- Updated README usage/security/license sections and added SECURITY,
  CONTRIBUTING, NOTICE and architecture documentation.

## Verification

- `python -m unittest discover -s tests`: 187 tests, OK.
- `python -m compileall -q main.py app scripts tests`: OK.
- `python -m pyflakes main.py app scripts tests`: no findings.
- `git grep` secret scan: no real tokens, e-mails, proxy credentials or
  machine-specific paths in tracked files.
- Open-source baseline: single clean root commit and tag `v5.0.0` in the
  separate `notion2api-web` copy.

## Known limitations

- The dashboard and `/api/*` are intentionally unauthenticated for local use;
  keep the service bound to localhost or behind an authenticated reverse proxy.
- Upstream Notion behavior can change without notice; the project is provided
  for research and personal integration use.
